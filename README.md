
# 🍕 Bella Vista Italian Cuisine

A responsive restaurant website for **Bella Vista**, an authentic Italian restaurant. Built with pure HTML and CSS.

---

## 📁 Project Structure

```
Bella Vista/
│
├── index.html        # Main HTML file
├── style.css         # Stylesheet
└── images/
    └── interior.png  # Restaurant interior image
```

---

## 🌐 Pages / Sections

| Section | Description |
|---|---|
| **Home** | Hero section with background image and CTA buttons |
| **Menu** | Appetizers with dish names, descriptions, and prices |
| **About Us** | Restaurant story and interior image |
| **Contact** | Reservation form and contact details |
| **Footer** | Quick links, opening hours, social media links |

---

## ✨ Features

- Fixed navigation header
- Full-screen hero section with background image overlay
- Menu section with hover animations
- Reservation form with input validation
- Responsive design for mobile, tablet, and desktop
- CSS animations (`fadeInUp`, `slideInLeft`)
- CSS custom properties (variables) for consistent theming
- Footer with social links and copyright

---

## 🎨 Color Palette

| Variable | Color | Use |
|---|---|---|
| `--primary-color` | `#e74c3c` | Buttons, accents |
| `--secondary-color` | `#2c3e50` | Header, headings |
| `--light-bg` | `#f8f9fa` | Section backgrounds |
| `--light-text` | `#666` | Descriptions |

---

## 📱 Responsive Breakpoints

- **768px** — Tablet: single column layout, stacked buttons
- **480px** — Mobile: smaller fonts, vertical nav links

---

## 🚀 How to Run

1. Clone or download the project folder
2. Add your restaurant image at `images/interior.png`
3. Open `index.html` in any browser

No installation or build step required — it's plain HTML & CSS!

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations, Media Queries)
